# Bit Operation Programs in C

This repository contains C programs based on bitwise operations.

Programs Included:

1. Even or Odd using bit operator
2. Power of 2 check
3. Swap using XOR
4. Add without + operator
5. Set particular bit
6. Clear particular bit
7. Toggle particular bit
8. Check bit set or not
9. Swap two bits
10. Swap even and odd bits
11. Left rotate bits
